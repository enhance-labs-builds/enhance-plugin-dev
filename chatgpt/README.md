# Enhance hosted canvas plugin

This development package connects to https://api.enhance3.karunalabs.ai/mcp/canvas-v1 through the host's OAuth flow. It contains the same four workflows and no executable or local filesystem connection. Only listed tools and host-provided capabilities are available. Source editing requires a host with access to that source; file publication requires a supported host upload and an advertised publication tool.

Register the MCP endpoint in ChatGPT developer mode, then test this portable package. If a local installation requires a registered app mapping, use the actual connection ID returned by the host; this artifact deliberately contains no invented app ID. Public listing requires provider review and is not implied by this package.
