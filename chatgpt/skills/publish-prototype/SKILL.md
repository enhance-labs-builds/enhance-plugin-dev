# Publish a prototype

Publish a built site to an Enhance canvas as a prototype people can click through, and give the canvas link.

## Tools

- The description of `prototype_publish` shows how to publish a build folder to a canvas, and how to update a prototype that is already there. Read it before the first publish.
- The description of `canvas_read` shows how to read what the canvas holds, including a prototype already on it.
