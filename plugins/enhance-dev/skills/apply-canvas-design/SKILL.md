# Apply a canvas design

Make the product's source match an approved design on an Enhance canvas, then update the prototype on that canvas from the new build.

## Tools

- The description of `canvas_read` shows how to read the design: the canvas's outline, or one screen as HTML. For code, read exact values from the design, never from a picture.
- The description of `canvas_render` shows how to get a picture of a screen.
- The description of `prototype_publish` shows how to update the prototype that is already on the canvas. Read it before publishing.
